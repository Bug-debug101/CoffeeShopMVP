# Coffee Shop Ordering System

A simple Java application for ordering coffee and pastries with delivery assignment.

## Features
- Order items (drinks and pastries)
- Add delivery address
- Automatic driver assignment
- Order confirmation with driver details

## Java Concepts Used

### Object-Oriented Programming
- **Inheritance**: Drink and Pastry extend MenuItem
- **Encapsulation**: Private fields with getters/setters
- **Polymorphism**: Method overriding in Drink and Pastry classes
- **Method Overloading**: getCost() method with different parameters

### Collections
- ArrayList for storing items in Order

### User Input
- Scanner class for console input
